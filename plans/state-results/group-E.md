## Things that cut across states

- Enhanced Voting's elections list moved: `…/results/public/api/jurisdictions/<slug>` returns `{shortName, elections: [{publicElectionId, electionDate, name}], childLocalities, …}`. The `…/api/elections/<slug>` path in the brief 404s on all three of WA, UT and VA.
- Enhanced Voting 200 responses carry no `Access-Control-Allow-Origin` and do carry `cross-origin-resource-policy: same-origin` (their 404s, oddly, send `access-control-allow-origin: *`).
- In every Enhanced Voting state here the per-contest `reportingStatus.reportingUnits/totalUnits` counts counties or localities, not precincts.
- Git Bash's bundled curl 8.8.0 (Schannel) fails with `curl: (43)` on Cloudflare hosts that renegotiate TLS (results.votewa.gov, results.texas-election.com); `C:\Windows\System32\curl.exe` (8.22) works. South Dakota was fetched with the Git Bash curl (it worked there); everything else with the Windows curl.
